# Mankeep人脉

在思源笔记里管理联系人、关系、组织经历、生日与往来记录。

**一人一篇文档，结构化资料保存在思源原生数据库里。**


本地优先 · 原生数据库 · 三种主题 · 可导出、可备份、无遥测

## 为什么是 Mankeep

- **不是通讯录孤岛**：每个联系人同时拥有一篇思源人物文档和一行数据库记录，既能在插件里管理，也能用搜索、双链、引用和同步。
- **关系看得见**：相关人、学校、单位、团体和经历连成关系图谱，支持聚焦、搜索、隐私模式和导出图片。
- **资料留得住**：互动、纪念日、账单、组织档案与 Logo 自动镜像到「人脉数据备份」；卸载插件后仍可从保留的文档和数据库恢复。

## 特色功能

### 首页与联系人

| 能力 | 说明 |
| --- | --- |
| 首页仪表盘 | 联系人数、近期生日、待联系、近期联系一屏掌握 |
| 快速搜索 | 首页顶栏按姓名/英文名搜索，回车查看全部结果 |
| 卡片 / 表格 | 两种列表视图，支持分组、标签、正序/倒序和分页 |
| 分组色头像 | 头像颜色与关系图谱分组一致，名字反白更醒目 |
| 两页详情 | 第一页资料/组织经历/纪念日，第二页互动记录与往来账单 |
| 一键联系 | 电话直接拨号、邮箱直接发信、家庭地址打开高德地图 |

### 组织与经历

- 学校、单位/企业、政府、团体独立建档，支持 Logo、简称、地址、备注。
- 学校可维护院系，企业可维护部门；添加经历时直接选择。
- 每段经历支持院系/部门、职位/学历、开始/结束日期和状态。
- 企业可记录成立时间、注册资本、实缴资本、法人、官网等工商信息。
- **组织详情只展示办公地址**，并支持点击地址直接打开高德地图。

### 日历、互动与账单

- 日历按月查看公历/农历生日、纪念日和当天互动。
- 点击日期可新建互动，多选联系人；同一场聚会分别写入每个人的记录。
- 互动类型：见面、电话、语音、视频、消息、礼物、其他；见面支持地点。
- 互动记录会同步到每个人物文档的「往来记录」小节，打开文档即可直接阅读。
- 纪念日按年重复，首页提前提醒。
- 往来账单支持金钱/物品/人情、欠款方向、到期时间、结清和逾期状态。

### 地图

![全局地图](https://cdn.jsdelivr.net/gh/ccztao/siyuan-mankeep@main/screenshots/global-map.jpg)

- 汇总家庭住址和当前在职公司地址，按地址合并展示联系人。
- 家庭地址和公司地址都支持**精准选点**，保存 6 位 GCJ-02 经纬度。
- 相同家庭地址可复用已有地址并共享坐标，一家人只需定位一次。
- **全局地图**把所有已保存坐标集中到一张地图：家庭红色、公司蓝色，点击标记查看地址和联系人。
- 支持高德 Web 服务 Key，配置后可按小区、道路、POI 精确搜索。

### 关系图谱

![关系图谱](https://cdn.jsdelivr.net/gh/ccztao/siyuan-mankeep@main/screenshots/graph.jpg)

> 图谱已匿名化：联系人显示为「联系人001…」，组织显示为「示例…」，Logo 已移除。

- 双向关系 + 组织经历，自动排布为紧凑的力导向图谱。
- 节点大小按连接数，颜色按分组；支持以我为中心、按组织聚焦、搜索高亮。
- 支持缩放、拖拽、适应页面、重新布局。
- **隐私模式**保留姓氏、隐藏名字，组织名称保持显示。
- **导出 PNG**：保留当前主题、连线、节点和组织 Logo，无点阵背景，6 倍分辨率。

### 数据与恢复

- vCard 3.0 导入导出，兼容常见 2.1/4.0 写法、折行、GBK、QP 编码。
- JSON 导出，包含互动、纪念日、账单、组织档案和组织经历。
- 互动/纪念日/账单/组织档案/Logo 自动镜像到「人脉数据备份」。
- 删除插件并清理私有数据后，只要保留人物文档、联系人总表数据库和「人脉数据备份」，即可完整恢复业务数据。
- 支持从备份恢复，也支持一键把已有互动同步到个人文档。

### 三种主题

![三种主题](https://cdn.jsdelivr.net/gh/ccztao/siyuan-mankeep@main/screenshots/theme-showcase.jpg)

领英蓝、暖橘、松绿三种配色，可在设置 → 主题颜色中切换；浅色、深色主题分别适配。

## 界面与交互

Liquid Glass 视觉：半透明玻璃面板、背景模糊、内高光、柔和阴影和胶囊式控件。桌面端通过右上角 Mankeep 图标打开，移动端保留全屏入口。

## 安装

1. `pnpm install && pnpm build`
2. 把 `dist/` 里的内容放到工作空间 `data/plugins/siyuan-mankeep/`
3. 重启思源，在「设置 → 集市 → 已安装」启用「Mankeep人脉」
4. 点击顶栏 Mankeep 图标，按向导初始化

## 开发

```bash
pnpm install
pnpm dev       # 监听构建到 dev/
pnpm build     # 生产构建到 dist/
pnpm check     # TypeScript 类型检查
pnpm package   # 生成 package.zip
```

## 数据存放与恢复

| 数据 | 位置 |
| --- | --- |
| 联系人人物文档、总表数据库 | 思源原生文档 / 数据库 |
| 互动、纪念日、账单、组织档案/经历、家庭坐标 | 插件私有 JSON，并镜像到「人脉数据备份」 |
| 设置、主题、工作区锚点、高德 Key | 插件私有 JSON |
| 备份文档 | 普通思源文档「人脉数据备份」 |

恢复步骤：

1. 重新安装插件
2. 初始化时填写原笔记本名称，复用已有「联系人总表」和数据库
3. 设置 → 数据出口 → 从备份文档恢复

界面主题偏好不在备份中；如果「人脉数据备份」也被删除，插件私有数据无法恢复。

## 已知限制

- 不包含 AI 识别、会议笔记捕获、CardDAV/CalDAV 在线同步。
- 一个联系人可以有多段组织经历；数据库「单位 / 学校」列只显示当前主组织，完整历史在插件私有数据中。
- 图谱只画「相关人」和「组织经历」两类关系，不做自动推断。
- 地图搜索依赖 OpenStreetMap/Photon 或高德 Web 服务 Key；没有 Key 时中国小区/POI 覆盖有限。
