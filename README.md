# Mankeep人脉
在思源笔记里管理联系人、关系、组织经历、生日与往来记录。一人一篇文档，结构化资料保存在思源原生数据库里。

## 功能

- 初始化向导：自动创建「Mankeep」笔记本、`联系人总表` 和原生数据库
- 联系人：卡片 / 表格、搜索、分组筛选（含亲戚、合作）、排序（姓名 / 最近更新 / 下次生日，可切换正序和倒序）、批量视图偏好；新建/编辑表单的保存按钮固定在右上角；详情里的电话、邮箱可直接拨打/发信
- 人物：一人一篇文档；支持英文名、与我的关系、籍贯、家庭住址、所在城市、兴趣爱好、财务状况、车辆、禁忌/过敏；详情里可直接添加已有组织的经历
- 纪念日：可为联系人记录相识、提亲、领证、结婚、入职、毕业等纪念日，按年重复，首页提前 60 天提醒
- 往来账单：金钱 / 物品 / 人情，区分我欠对方 / 对方欠我，记录金额、发生时间、可选到期时间，支持结清与逾期提醒
- 生日：公历 / 农历，日期框内直接切换公历/农历；按下一次实际发生日排序；首页近期生日（本周/本月/未来30天或过去30天）
- 互动：见面/电话/消息/礼物记录、时间线、最近联系；互动记录可编辑日期、类型、地点和内容；见面类型支持填写地点，同一事件的其他参与人会显示在联系人互动记录中
- 图谱：双向 relation + 全幅点阵背景、紧凑力导向直线关系图谱；节点大小按连线数（本人最大）、颜色按固定分组顺序；连线避开节点且不重合，游离组件间距缩小、放不下时整体缩放；支持图谱搜索、聚焦、缩放、拖拽与重新布局
- 组织：独立创建 / 编辑学校、单位、团体，可上传 Logo、设置简称和地址；成员经历分「院系/部门」与「职位/学历」，带开始/结束日期；学校支持在读/在职（教职工）/毕业/离职，并可记录可点击的官网、维护院系列表；单位支持在职/离职；单位/企业可记录成立/注册时间、注册资本（万元）、实缴资本（万元）、注册地址、法人和网址，并可维护部门列表；顶部搜索
- 数据：vCard 3.0 导入导出（兼容 2.1/4.0 常见写法、折行/GBK/QP）、JSON 备份；互动、纪念日、往来账单、组织档案/经历自动镜像到普通文档「人脉数据备份」，清理插件数据或重装后可从备份恢复
- 本人：在设置页标记「我」，列表显示「我」，关系图谱以本人为中心（联系人详情不再单独放设为本人的按钮）
- 首页顶栏直接搜索联系人；新增「日历」页：按月展示公历/农历、生日、纪念日和近期联系；点击日期可新建互动并多选联系人，点击事件可打开联系人
- 桌面顶栏、左侧停靠栏、移动端全屏入口

## 界面

采用 Liquid Glass 视觉：半透明玻璃面板、背景模糊、内高光、柔和阴影与胶囊式控件；浅色/暗色主题分别适配。

## 开发

```bash
pnpm install
pnpm dev       # 监听构建到 dev/
pnpm build     # 生产构建到 dist/
pnpm check     # TypeScript 类型检查
pnpm package   # 生成 package.zip
```

构建产物是单文件 `dist/index.js` + `dist/index.css`，符合思源插件加载要求。

## 安装

1. `pnpm build`
2. 把 `dist/` 里的内容放到工作空间 `data/plugins/siyuan-mankeep/`
3. 重启思源，在「设置 → 集市 → 已安装」启用「Mankeep人脉」
4. 点击顶栏 Mankeep 图标（或左侧停靠栏「Mankeep」），按向导初始化

> 从旧包名 `siyuan-renmai` 升级时：把新包放到 `data/plugins/siyuan-mankeep/` 后，首次启动会自动迁移旧私有数据。请在「集市 → 已安装」禁用旧的 `siyuan-renmai`，避免出现两个入口。

## 已知限制

- 不包含 AI 识别、会议笔记捕获、CardDAV/CalDAV 在线同步。
- 一个联系人可以有多段组织经历（学校、单位、团体可同时存在）；联系人数据库的「单位 / 学校」列显示当前主组织，完整历史在插件 JSON 里。
- 组织档案/经历和 Logo 是插件私有数据，不是独立组织文档；卸载插件通常保留，手动清理插件数据会丢失，详见「数据存放与卸载」。
- 图谱只画「相关人」和「组织经历」两类关系，不做自动推断。
- 互动记录保存在插件私有目录；清理插件数据会丢失，人物文档和数据库不受影响。

## 数据存放与卸载

| 数据 | 存放位置 | 卸载或清理插件后 |
|---|---|---|
| 联系人人物文档、联系人总表数据库、字段 | 思源原生文档 / 数据库 | 保留，随思源工作区备份和同步 |
| 互动、纪念日、往来账单、组织档案/经历、组织 Logo | 插件私有 JSON：`data/storage/petal/siyuan-mankeep/` | 禁用或卸载插件一般不删除；手动清理插件数据会丢失 |
| 设置、工作区锚点、提醒设置 | 插件私有 JSON（旧包名数据会自动迁移） | 一般保留；重装后可重新扫描工作区 |
| 数据备份 | 普通思源文档「人脉数据备份」 | 不会被卸载插件删除 |

需要分清三件事：

- **禁用插件**：只停止加载插件，不改动任何数据。
- **卸载插件**：移除插件代码。联系人人物文档、数据库不随插件卸载删除；插件私有数据通常也会保留，但它不是独立文档，清理插件数据时就可能消失。
- **清理插件数据 / 删除工作区**：会删除插件私有 JSON，组织经历、Logo、互动、纪念日、账单随之丢失。

组织经历和 Logo 不是独立组织文档，而是插件私有数据；它们会自动写入「人脉数据备份」文档。清理插件数据或重装后，可在设置 → 数据出口 → 从备份文档恢复。

备份文档包含：互动、纪念日、往来账单、组织档案/经历、组织 Logo。它不包含联系人人物文档和原生数据库本身，这两类数据由思源工作区负责备份。
