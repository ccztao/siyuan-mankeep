# Mankeep人脉

在思源笔记里管理联系人、关系、组织经历、生日、互动与往来记录。一人一篇文档，结构化资料保存在思源原生数据库里。


## 亮点

- 联系人、组织、关系图谱、日历和地图集中在一个工作台
- 分组色头像、两页人物详情、分页联系人列表
- 学校院系 / 企业部门、组织经历、Logo 和工商信息
- 互动记录同步到每个人物文档的「往来记录」
- 家庭 / 公司地址精准选点，全局地图集中展示
- 三种主题：领英蓝、暖橘、松绿
- 图谱隐私模式与 6 倍 PNG 导出
- vCard / JSON 备份，互动、账单、纪念日、组织档案自动镜像到「人脉数据备份」

## 特色功能

### 联系人

卡片 / 表格、分页、搜索、分组筛选、正序倒序；详情分「资料」和「互动与往来」两页，电话可拨号、邮箱可发信、家庭地址可打开所选地图。

### 组织

学校、单位/企业、政府、团体独立建档；学校维护院系，企业维护部门；记录院系/部门、职位/学历、起止日期和状态；企业支持工商信息。组织详情只展示办公地址。

### 互动与账单

见面、电话、语音、视频、消息、礼物、其他；支持地点、多人互动、日历新建。往来账单支持欠款方向、金额、到期、结清和逾期。互动会同步到人物文档。

### 地图

家庭地址和公司地址都可精准选点，保存 6 位坐标；相同家庭地址可复用并共享坐标。地图页按地址合并联系人，全局地图支持家庭红 / 公司蓝标记，点击查看地址和联系人；设置中可选高德 / 百度。

## 安装

把本目录（`plugin.json`、`index.js`、`index.css`、`icon.png`、`preview.jpg`、`screenshots/`）放到工作空间的 `data/plugins/siyuan-mankeep/`，重启思源，在「设置 → 集市 → 已安装」启用「Mankeep人脉」。

首次打开点击右上角 Mankeep 图标，按向导创建「Mankeep」笔记本、`联系人总表` 文档和数据库。已有同名笔记本/文档会复用。

## 数据与恢复

保留人物文档、联系人总表数据库和「人脉数据备份」三样，即可在重装后恢复互动、纪念日、账单、组织档案/经历、Logo、提醒天数和本人设置。

恢复步骤：

1. 重新安装插件
2. 初始化时填写原笔记本名称
3. 设置 → 数据出口 → 从备份文档恢复

人物文档和数据库属于思源原生数据；界面主题偏好不在备份中。若「人脉数据备份」也被删除，插件私有数据无法恢复。
